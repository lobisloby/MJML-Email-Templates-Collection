## 🛠️ Installation & Usage

### Prerequisites

- Node.js (v14+)
- npm or yarn

### Setup

```bash
# Clone the repository
git clone https://github.com/yourusername/mjml-email-templates.git

# Navigate to the project
cd mjml-email-templates

# Install MJML globally
npm install -g mjml

---

## ⚡ Compile MJML Templates

Easily compile your MJML email templates into HTML files.

### 🔹 Single File Compilation

```bash
mjml wellness/index.mjml -o wellness/index.html
```

### 🔹 Watch Mode (Auto-Compile on Save)

```bash
mjml --watch wellness/index.mjml -o wellness/index.html
```
